# 💳 Finova Bank Landing Page

A modern banking landing page built with **React** and **Tailwind CSS**. This project was created to practice React fundamentals such as component-based architecture, props, and reusable UI while designing a clean and professional banking website.

## ✨ Features

- Modern banking landing page UI
- Clean and responsive layout
- Component-based React architecture
- Dynamic customer testimonials using props
- Reusable footer sections
- Call-to-action section
- Modern footer with navigation links and newsletter subscription
- Built with Tailwind CSS for fast styling

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- Tailwind CSS
- Remix Icons

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/finova-bank.git
```

Navigate to the project

```bash
cd finova-bank
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
